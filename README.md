# json-latest

A lightweight data service and automation pipeline that tracks, fetches, and parses scheduled YouTube live streams across sports channels. This repository serves as the primary data source powering [cadeojogo.vercel.app](https://cadeojogo.vercel.app/).

---

## 📌 Overview

The core script (`script.js`) queries the YouTube Data API v3 for upcoming live broadcasts across configured channels, filters for streams scheduled for the current or specified date (adjusted to Brasília Time / `UTC-3`), and outputs a structured `lives.json` file.

Updates are automated using GitHub Actions workflows triggered by an external cron service.

---

## 🚀 Features

- **YouTube Data API v3 Integration**: Fetches channel metadata, upcoming live broadcasts, and exact `scheduledStartTime` timestamps.
- **Timezone Awareness**: Handles comparisons in UTC and formats human-readable times into Brasília Time (`America/Sao_Paulo` / `UTC-3`).
- **Configurable Channels**: Default set of major Brazilian sports channels with override support via environment variables.
- **Automated Workflow**: Workflow execution triggered via GitHub Actions (`workflow_dispatch`) by external cron jobs.
- **Clean JSON Output**: Emits structured data consumed by frontend applications.
